# Documents-verification-system-using-Blockchain
# 🔐 Blockchain Document Verification System

A modern **UI-based document verification system** that uses blockchain concepts to ensure document authenticity.  
This project focuses on **clean UI/UX**, step-based flow, and hash-based verification.

---

## 📌 Project Overview

This system allows users to:
- Connect a wallet
- Upload a document
- Generate a secure hash
- Store the hash
- Verify document authenticity later

The entire flow is **step-by-step**, visually guided, and easy to understand for non-technical users.

---

## 🎯 Key UI/UX Features

### 🧭 Step-Based Navigation
- Clear **3-step progress indicator**
  1. Wallet Connection  
  2. Document Upload  
  3. Verification  

This helps users always know **where they are** in the process.

---

### 🎨 Clean & Modern UI
- Gradient background with soft colors  
- Rounded cards and buttons  
- Consistent typography  
- Proper spacing and alignment  

Designed to look professional and trustworthy.

---

### 👛 Wallet Connection Interface
- Dedicated wallet connection section
- Status indicator (connected / not connected)
- Wallet details shown only after successful connection  
  - Wallet Address  
  - Network  
  - Balance  
  - Connection Type  

This reduces confusion and improves clarity.

---

### 📂 Document Upload Experience
- Drag & drop upload area
- Click-to-upload support
- File preview with:
  - File name
  - File size
  - File type  

This gives immediate feedback to the user.

---

### 🔑 Hash Generation Display
- Automatically generates SHA-256 hash
- Partial hash preview for readability
- Options to:
  - Copy hash
  - View full hash in modal  

Improves transparency without overwhelming the user.

---

### ✅ Verification Result UI
- Clear **success / failure cards**
- Icon-based visual feedback
- Detailed verification information shown neatly
- Easy-to-understand messages  

Users instantly know if the document is verified or not.

---

### 📜 Transaction History Section
- Collapsible transaction history
- Clean card-based layout
- Displays:
  - Hash
  - Sender
  - Time
  - Block number
  - Status  

Keeps UI clean while still providing details when needed.
